## 2. 塑造價值標籤（DHV）：低成本的信號傳播

- **信號制理論**：人類傾向透過簡短、亮眼的「標籤」快速了解事物。與其等別人揣摩，不如主動提供一個有亮點的身份標籤。
    
- **標籤包裝技巧**：
    
    - _避開劣勢_：如果具體職位不夠亮眼，就聊整體**行業**（例如：不說人事，說時尚產業自由工作者）；若行業不行，就用**興趣愛好或能力**作為身份。
        
    - _呈現形式大於本質_：不存在真正厲害的身份，只有不好的呈現方式。可透過「展示面 + 簽名 + 名字 + 標籤」打造價值名片。
        
    - _避免誤區_：切忌過度展示與炫耀，貪多反而無效。
        

## 3. 拋出篩選標準：內在價值的「拋磚引玉」

- **引導對方展現**：透過詢問對方對感情、生活或技能（如：會不會做菜）的看法，給女生一個展示自我內在價值的機會。
    
- **互相吸引的共識**：當雙方同時完成內在價值的展現，就能形成「三觀相符」的來電感，讓男生後續的熱情追求顯得「出師有名」。
    
- **對話引導竅門**：
    
    - 想展示什麼價值，就問相關的問題（例如：問對方會不會煮飯，目的是為了引出「自己也會做菜且嚮往共同生活」的觀點）。
        
    - 若對方的答案不符預期，可以表達不認同並說明理由，這能展示深層思考，塑造獨特的人格魅力。
